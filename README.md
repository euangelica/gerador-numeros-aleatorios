# 🎲 Gerador de Números Moderno

Um aplicativo web interativo de sorteio de números desenvolvido com foco em design limpo, usabilidade e uma experiência de usuário (UX) refinada.

## 🚀 Funcionalidades

- **Página de Início Exclusiva:** Uma tela de boas-vindas acolhedora e moderna para introduzir o usuário ao sistema, com navegação fluida.
- **Sorteio Personalizável:** Escolha a quantidade de números e defina o intervalo exato (mínimo e máximo).
- **Interface Minimalista:** Layout centralizado em formato de cartão com identidade visual em tons de rosa e animações suaves de *hover* via CSS.
- **Janela Flutuante (Modal):** O resultado do sorteio aparece em destaque com uma animação elegante.
- **Histórico Inteligente:** Os resultados anteriores ficam salvos na página principal acompanhados de ícones minimalistas, data e hora exata de cada sorteio.
- **Rodapé Personalizado:** Com autoria e link direto para o perfil profissional.

## 🛠️ Tecnologias Utilizadas

O projeto foi construído utilizando tecnologias nativas (Vanilla):
- **HTML5** (Estruturação semântica e multiplataforma)
- **CSS3** (Flexbox, animações `transition`/`transform` e estilização responsiva)
- **JavaScript** (Lógica de sorteio, manipulação do DOM e histórico em tempo real)

## 💻 Como executar o projeto

1. Faça o clone ou o download deste repositório.
2. Abra a pasta do projeto no seu editor de código (como o **VS Code**).
3. Abra o arquivo `inicio.html` ou `index.html` diretamente no seu navegador de preferência (ou utilize a extensão *Live Server* do VS Code).
