# 🎲 Gerador de Números Moderno

Um aplicativo web interativo de sorteio de números desenvolvido com foco em design limpo, usabilidade e uma experiência de usuário (UX) refinada.

## 🚀 Funcionalidades

- **Sorteio Personalizável:** Escolha a quantidade de números e defina o intervalo exato (mínimo e máximo).
- **Interface Moderna:** Layout centralizado em formato de cartão com a identidade visual em tons de rosa.
- **Janela Flutuante (Modal):** O resultado do sorteio aparece em destaque com animação de janela flutuante.
- **Histórico Inteligente:** Os resultados anteriores ficam salvos na página principal acompanhados de ícones minimalistas, data e hora exata do sorteio.
- **Controles Dinâmicos:** Botões de incremento e decremento para facilitar a escolha da quantidade.

## 🛠️ Tecnologias Utilizadas

O projeto foi construído utilizando apenas tecnologias nativas (Vanilla):
- **HTML5** (Estruturação semântica)
- **CSS3** (Flexbox, estilização de cartões, modal e responsividade)
- **JavaScript** (Lógica de sorteio, manipulação do DOM e registro de histórico com data/hora em tempo real)

## 💻 Como executar o projeto

1. Faça o clone ou o download deste repositório.
2. Abra a pasta do projeto no seu editor de código (como o **VS Code**).
3. Abra o arquivo `index.html` diretamente no seu navegador de preferência (ou utilize a extensão *Live Server* do VS Code).
